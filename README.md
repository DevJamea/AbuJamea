# منصة عائلة أبو جامع — Abu Jame' Family Platform

منصة عائلية فلسطينية حديثة لإدارة بيانات العائلات والأفراد والطلبات والأخبار والإعلانات مع مراعاة الأمان والخصوصية.

## المتطلبات
- Node.js 20+
- npm 10+
- PostgreSQL 15+

## التقنيات الحالية
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Drizzle ORM
- PostgreSQL

## الإعداد المحلي
1. تثبيت الحزم:
   - `npm install`
2. إنشاء ملف البيئة:
   - انسخ `.env.example` إلى `.env`
3. تحديث اتصال قاعدة البيانات داخل `.env`
4. دفع المخطط إلى PostgreSQL:
   - `npx drizzle-kit push`
5. تشغيل التطوير:
   - `npm run dev`

## متغيرات البيئة
- `DATABASE_URL` رابط PostgreSQL.
- `NEXT_PUBLIC_APP_URL` رابط التطبيق العام.

## فحص الجودة
- توليد الأنواع: `npx next typegen`
- فحص TypeScript: `npm exec tsc -- --noEmit --pretty false`
- بناء الإنتاج: `npm run build`

## البنية المعمارية
راجع ملف:
- `docs/architecture-plan.md`

## قاعدة بيانات
المخطط الكامل موجود في:
- `src/db/schema.ts`

## ملاحظات أمنية
- يمنع تضمين أي أسرار داخل الكود.
- البيانات الحساسة لا تُعرض للعامة.
- حسابات الإدارة مقيدة بقاعدة `admin-` على مستوى قاعدة البيانات.
- الهاتف محكوم بصيغة 10 أرقام في القيود الخلفية.

ثم المراحل التالية (التسجيل، اللوحات، النشر، الإشعارات، الاستيراد/التصدير، الاختبارات).
